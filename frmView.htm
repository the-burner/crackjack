Error Logs

Click on the Errors buttons on any of the drills screens to reach this screen. A list of the last 200 errors for that drill will be displayed, most recent first. For the Count Drill errors, the last column will contain the word View. Click this to examine the error.

Delete All

Click this button to erase all error logs and start anew.

Oldest First

Select to reverse the display order

View Counts

This button is only on the Counts Drill error log. It will take you to another screen that will display the counts of the hands that have given you problems.
